# @sfmc-bds/module-qq-link

SFMC QQ↔MC 身份绑定、游玩门槛、踢人和事件同步模块。

## 能力

| 能力 | 说明 |
| --- | --- |
| 绑定 | QQ 侧获取短码，在游戏内执行 `/c:bind` 后发送数字码 |
| 游玩门槛 | 未绑定玩家可进服，但暂时是访客，不能移动或交互；绑定成功后解除限制 |
| 踢人 | 轮询管理动作队列，对在线玩家执行服务端 `kick` 命令并回执 |
| 状态与事件 | 向平台同步在线状态、玩家资料及游戏事件 |

## 绑定与入服

1. 在 QQ 对机器人发送「绑定」，取得短码。
2. 进入服务器，执行 `/c:bind`，在 60 秒内将纯数字短码发到聊天栏。
3. 绑定成功后，模块解除访客和移动限制。操作员恢复操作员权限，其他玩家成为成员。

模块启动时关闭原版 allow-list，以便未绑定玩家能进服完成绑定。若平台暂时无法确认绑定状态，新进入的玩家会继续受限。计划部署到已有服务器时，应先备份并安排实际运行验收。

QQ 侧的审批与配置行为由平台服务管理。本模块不再向 BDS 原版 `allowlist.json` 写入玩家。

## 依赖

- `@sfmc-bds/sdk` 运行时。
- 平台 db-server 的 QQ 绑定、管理动作和事件接口。
- 与目标 BDS 对应的 Minecraft Script API 版本。

## 开发

```bash
pnpm install --frozen-lockfile
pnpm run typecheck
pnpm run lint
```

联调时用 `sfmc mod install qq-link --from dir:<本仓路径> --link` 安装模块，构建并部署行为包，然后在安排好的维护窗口重启 BDS。验收未绑定入服、绑定解锁、操作员权限还原、踢人回执和重新进服。
